SQL Around the World

Part 1

Using SELECT, FROM, and WHERE

In this lab, we will begin learning the SQL language. SQL is a query language used to find data in a database. Our first 3 words are SELECT, FROM, and WHERE.

The SELECT command finds values in a database and returns them to us.

The FROM keyword names from which table to find the values.

The WHERE keyword specifies the conditions where the values match what we are looking for.

Excel Functions Quick Reference
=CONCAT(text1, text2, ...)

Combines multiple text strings into a single string. E.g. =CONCAT(L2, ", ", M2)

=LOWER(text) / =UPPER(text)

Converts text characters to lowercase or uppercase.

=LEFT(text, num) / =RIGHT(text, num)

Extracts characters from the beginning (left) or end (right) of a text string.

=MID(text, start_num, num_chars)

Extracts a substring from inside a text string starting at a specified character position.

=COUNT(range) / =COUNTA(range) / =COUNTBLANK(range)

Counts numbers only (COUNT), non-empty cells (COUNTA), or blank empty cells (COUNTBLANK).

=COUNTIF(range, criteria)

Counts cells in a range matching a condition. E.g. =COUNTIF(H2:H21, "Australia")

=SUMIF(range, criteria, [sum_range])

Sums values in a sum range when criteria are met. E.g. =SUMIF(H2:H21, "Australia", S2:S21)

=VLOOKUP(lookup_val, table_array, col_idx, [range_lookup])

Searches the first column of a table and returns a value from the specified column in the same row. Use FALSE for exact matches.

Module 3: Ordering and Limiting

Curriculum Overview & Learning Objectives

Master row ordering and truncation across astronomical, biological, and demographic datasets using standard SQL clauses.

Curriculum Exercises (10 Modules):
  • ORDER BY & ASC: Sort planetary moons by radius in ascending order.
  • DESC Keyword: Rank moons from largest to smallest by radius.
  • LIMIT Clause: Restrict query output to top-N entries (e.g. 5 largest moons).
  • Demographic Analysis: Find the 10 largest nations by land area and population.
  • Mammal Sleep Patterns: Filter carnivores and sort by daily sleep hours.
  • Clause Sequencing: Master the syntactic hierarchy of WHERE, ORDER BY, and LIMIT.

Module 4: Successful Movies

Curriculum Overview & Learning Objectives

Master box office analytics and cinema data filtering across 50 years of motion picture achievements using core SQL commands.

Curriculum Exercises (10 Modules):
  • SELECT All Columns: Inspect full table schemas and data rows.
  • Column Projection: Select targeted attributes (title, director, rating).
  • Exact String Filtering: Query films with exact rating matches using WHERE rating = 'PG'.
  • Numerical Comparisons: Filter movies with critically acclaimed ratings (rating > 7.5).
  • Column-to-Column Comparison: Isolate financial underperformers where revenue < budget.
  • ORDER BY & DESC: Sort films descending by critical audience score.
  • Chronological Sorting: Order movies chronologically by release year.
  • Top-N Analysis: Combine ORDER BY revenue DESC with LIMIT 5.
  • Compound Conditions: Combine range conditions with sorting.
  • The Ultimate Cinema Query: Combine WHERE, ORDER BY, and LIMIT.
